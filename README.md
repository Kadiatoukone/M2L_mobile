
# M2L Web App

Application web développée dans le cadre du projet M2L (Maison des Ligues de Lorraine).
pour plus d'information , se renseigner avec le cahier des charges ci-joint : 

Cette application permet la gestion des fonctionnalités principales de la M2L :
- Connexion des utilisateurs (gestionnaires)
- gestion des gestionnaires
- ajout , modification , suppression des salles 
- Consultation des informations des salles 
-  Gestion des Réservations
- Interface mobile
- Communication avec une API rest

---

##  Objectifs 

Ce projet a pour but de mettre en pratique :
- Le développement Front-End moderne
- La communication avec une API REST
- La gestion de projet (Gantt, cahier des charges,MCD ,MLD,   MPD ,  )
